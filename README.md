# File Handling Tasks

C++ solutions for three file handling tasks.

- `Task1.cpp`: reads student details and writes them to `file.txt`.
- `Task2.cpp`: prints the contents of `fruit.txt` and appends `Fresh Fruits`.
- `Task3.cpp`: writes `Hello Everybody` to `welcome.txt`, then replaces `body` with `one`.

Compile each source file separately with a C++ compiler. The programs create or update their text files in the current working directory.
